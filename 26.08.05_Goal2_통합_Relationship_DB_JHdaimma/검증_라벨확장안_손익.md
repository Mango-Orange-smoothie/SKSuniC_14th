# 3. 대가 — 3건

## 🔴 대가 ① `Surface_Roughness` 378.4배 → 9.8배

```
main   정상구간 0.04%  →  위험구간 13.16%   =  378.4배
다     정상구간 2.40%  →  위험구간 23.54%   =    9.8배
```

### 왜 이렇게 떨어지나 — 분모가 달라진 것입니다

두 숫자 다 맞습니다. **세는 대상이 다릅니다.**

```
378배  =  "파티클만 단독으로 난 판" 기준
           표면이 매끄러운 구간에서는 그런 판이 거의 없다 (0.04%)

9.8배  =  "파티클이 난 모든 판" 기준
           표면이 매끄러워도 파티클은 100장 중 2~3장 난다 (2.4%)
```

표면이 정상인 구간에서 나는 파티클은 **거의 다 다른 불량과 같이 납니다.**
`pure` 라벨은 그런 판을 파티클로 안 세기 때문에 정상구간 비율이 0.04%로 내려가고,
그래서 배수가 폭발한 것입니다.

**현장 질문으로 바꾸면 이렇습니다.**

| 질문 | 답 |
|---|---|
| "표면이 정상이면 파티클이 안 나나요?" | **아니요. 100장 중 2~3장은 납니다** ← 9.8배 쪽 |
| "표면이 정상이고 다른 문제도 없으면?" | 1만 장 중 4장 ← 378배 쪽 |

**경보를 거는 목적으로는 9.8배가 정직합니다.** 다만 발표 임팩트는 378배가 큽니다.

## 🟡 대가 ② `CLN_Pressure` 상위 등급 T1 → T2

```
main   CLN_Pressure  상위 T1   [Remain_Coat:T1]
다     CLN_Pressure  상위 T2   [Remain_Coat:T1 · Particle:T2]
```

한 인자가 두 불량의 원인이 되면 **더 낮은 등급을 대표로 씁니다**(보수적 병합).

- **`Remain_Coat`에 대해서는 여전히 T1**이고 `actionable=True`도 유지됩니다
- Agent가 "즉시조치" 대신 **"조건부조치"** 라고 답합니다
- *"즉시조치 인자 4개"* 로 세던 것을 **3개**로 고쳐야 합니다

> `CLN_Flow`가 이미 같은 이유로 T2입니다. **새로운 종류의 문제는 아닙니다.**

## 🟡 대가 ③ Micro_Crack은 Health Index에 여전히 안 들어갑니다

감시 데이터 41건으로 잰 방향이 반대라서이고, **라벨로는 못 넘습니다.**
