## 표본 하한을 50으로 올려도 소용없습니다 (시뮬 완료)

`MIN_N_DATASET = 10 → 50` 으로 바꿔 전체를 다시 돌린 결과:

```

안 바뀌는 것  티어 분포 · delta · 경계값 · Agent 계약 전부 동일
게이트        10건 전부 통과 → Micro_Crack 이 Health Index 에 들어감
```

**그런데 점수가 무의미합니다.**

# 14. XGBoost + SHAP를 뺀 이유

```
XGBoost   랜덤포레스트와 같은 질문(다변량 중요도)  →  역할 중복
          셋이 되면 "2개 중 몇 개" 등급 규칙이 무너짐

SHAP      "이 한 샷이 왜 불량인가"(국소 설명)
          우리 산출물은 인자별 등급표라 들어갈 자리가 없음
```

**성능이 아니라 조치 가능성을 기준으로 골랐습니다.**
