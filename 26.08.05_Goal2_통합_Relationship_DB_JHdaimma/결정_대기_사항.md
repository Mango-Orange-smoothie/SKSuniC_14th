# 📮 김시우님께 알려야 할 것 (오늘 변경분)

## `repro_state`의 `실패`가 **두 값으로 갈렸습니다**

```
전  실패(데이터셋간 방향 불일치)   ← 하나로 뭉쳐 있었음
후  실패(데이터셋간 방향 불일치)   ← 원본과 r1이 서로 어긋난 경우 (현재 0건)
    실패(도메인 방향과 불일치)     ← 둘은 일치하는데 도메인과 반대 (현재 3건)
```

### ✅ 코드는 안 고치셔도 됩니다

두 값 모두 **`"실패"`로 시작**하므로 `~startswith("실패")` 필터는 **동작이 완전히 같습니다.**

### 다만 사유가 바뀝니다

지금 제외되고 있는 `Micro_Crack` 2건의 실제 데이터입니다.

| defect / 인자 | 원본 delta | r1 delta | 서로 일치? | 도메인 기대 |
|---|---|---|---|---|
| `Micro_Crack / Cooling_Flow` | +0.069 | +0.065 | **✅** | 음수 |
| `Micro_Crack / Cooling_Water_Temp` | −0.100 | −0.013 | **✅** | 양수 |
| `Particle / CLN_Pressure` | +0.012 | +0.012 | **✅** | 음수 |

**"김시우님 데이터와 제 데이터가 다르다"가 아니라, "두 데이터 모두 도메인과 반대"입니다.**
데이터셋 비대칭 때문에 생긴 문제가 아니라는 뜻이라, 판단이 달라지실 수 있어 알려드립니다.
